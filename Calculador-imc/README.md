# Calculadora de IMC

Calculadora de índice de massa corporal feita com HTML, CSS e JavaScript puro, sem dependências.

## Funcionalidades

- Cálculo em tempo real ao mexer no campo numérico ou no controle deslizante
- Medidor em arco com ponteiro animado e classificação da OMS
- Faixa de peso normal para a altura informada e quanto falta para chegar nela
- Histórico das últimas 8 medições salvo no navegador (`localStorage`)
- Tema claro e escuro automático, layout responsivo e navegação por teclado

## Como rodar

Baixe a pasta e abra o `index.html` no navegador.

## Estrutura

- `index.html`: estrutura da página
- `style.css`: estilos, medidor em arco (`conic-gradient`) e modo escuro
- `script.js`: cálculo, medidor e histórico
